# Cult of Psyche transcript wiki: rules for Claude Code

This folder is an Obsidian vault built from the CultCodex database: every episode transcript, plus notes for the people, topics and lore that connect them. It follows Andrej Karpathy's "LLM wiki" pattern. Raw sources stay untouched, a linked wiki sits on top, and you grow the wiki over time so answers compound instead of being re-derived from scratch.

## Layout

| Path | What it is | Who writes it |
|---|---|---|
| `index.md` | Catalog of every note with one-line summaries. **Read this first.** | exporter |
| `log.md` | Append-only history of exports and wiki work | exporter + you (append only) |
| `raw/transcripts/` | One note per episode: the full transcript, timestamped, with YouTube links | exporter. **Never edit.** |
| `wiki/episodes/` | One note per episode: summary, guests, topics, lore, key quotes, link to its transcript | exporter |
| `wiki/people/` | One note per person: bio, appearances, mentions, quotes. `aliases` holds alternate names | exporter |
| `wiki/topics/` | One note per topic, listing its episodes | exporter |
| `wiki/lore/` | One note per lore entry: canon status, entry text, episodes | exporter |
| `wiki/concepts/` | Recurring ideas, running bits, arcs, feuds, patterns across episodes | **you** |
| `wiki/analyses/` | Answers to questions worth keeping, comparisons, timelines | **you** |

## Hard rules

1. **Only write in `wiki/concepts/`, `wiki/analyses/`, and append to `log.md`.** Everything else is regenerated by `npm run brain:export` in the CultCodex repo and your edits there would be overwritten. If an exporter-owned note is wrong, say so and point at the fix in the database (admin panel), don't patch the note.
2. **Cite the transcript for every claim.** Link the transcript note and the timestamp: `[[2025-05-15 Title (transcript)]] at [1:02:14](https://www.youtube.com/watch?v=ID&t=3734s)`. Copy the timestamp link from the transcript paragraph you're quoting. If you can't find a source line, say the claim is unverified.
3. **Summaries are AI-generated; transcripts are the ground truth.** Episode summaries, bios and lore entries came from an earlier enrichment pass. When they disagree with the transcript, trust the transcript and note the conflict.
4. **Transcripts are auto-captions or Whisper output.** Names get misspelled and speakers are often unlabeled. Search for spelling variants (check a person's `aliases`) and don't attribute a line to someone unless the transcript or context makes it clear.

## How to find things

- Start at `index.md`, then follow `[[links]]`. A person note lists every episode they appear in; an episode note links to its transcript.
- Search transcripts directly with Grep over `raw/transcripts/` (they're large; search, don't read whole files unless you need to). Search for the phrase and its likely mis-transcriptions.
- The date prefix on episode and transcript names sorts them chronologically, so "first time X came up" is usually the earliest matching filename.
- Before a big question, check `wiki/concepts/` and `wiki/analyses/`: it may already be answered.

## Workflows

### Ingest (`/ingest`)
After a new export, `log.md` lists the new episodes. For each one: read its episode note and skim its transcript, then update or create the concept notes it touches (add the new evidence with citations, note contradictions with earlier episodes), and append one log entry: `## [YYYY-MM-DD] ingest | <n> episodes` with the notes you changed. One episode usually touches 3–10 concept notes.

### Ask (`/ask <question>`)
Answer from the wiki first, then the transcripts. Cite everything. If the answer took real digging and would be useful again, save it to `wiki/analyses/<short title>.md` and log it.

### Lint (`/lint`)
Health check: concept notes with no citations, claims that contradict newer transcripts, concepts mentioned in several notes but lacking their own page, analyses superseded by later episodes, broken links. Report first; fix only in `wiki/concepts/` and `wiki/analyses/`.

## Concept note shape

```markdown
---
type: concept
tags: [concept]
first_seen: 2024-03-02
---
# <Name>

One paragraph: what it is, in plain words.

## Timeline
- 2024-03-02: first mention. [[2024-03-02 Title (transcript)]] at [12:04](url)
- 2024-06-11: turns into a running bit. [[...]] at [...](url)

## Who's involved
[[Person]] · [[Person]]

## Open questions / contradictions
```

Name concept notes for the thing itself ("The Great Ban Wave"), not a category ("Drama"). Link people, episodes and lore by their exact note names so Obsidian's graph connects them.

## Tone

Plain and direct. Quote the transcript rather than paraphrasing it smoother. When the evidence is one offhand line, say so.
