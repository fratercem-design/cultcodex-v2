## Verified OK

- All 94 API routes. Every admin route gates on an admin session, `adminOnly()` or an HMAC key. Cron routes need a bearer token. Stripe webhook verifies signatures via `constructEvent`. `/api/live/toggle` uses a header secret with `timingSafeEqual`.
- The remaining `dangerouslySetInnerHTML` sinks go through `jsonLdScript()`, are a static theme bootstrap, or are numeric-only SVG (card art).
- `$queryRawUnsafe` is used only in admin routes or with parameter placeholders (`rate-limit.ts`, `llm-budget.ts`).
- Images: all `<Image>`/`<img>` have `alt` (decorative ones use `alt=""`). All `target="_blank"` links carry `rel="noopener…"`.
- `robots.ts` disallows member/account surfaces.
